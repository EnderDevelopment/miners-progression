# Miner's Progression

Miner's Progression is a Minecraft plugin designed to enhance the mining experience by allowing players to level up as they mine various types of ores. This plugin is perfect for servers that want to add a progression system based on mining activities, encouraging players to explore and gather resources.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Players will level up by mining specific types of ores: Stone, Coal Ore, Iron Ore, Gold Ore, and Diamond Ore.
2. Each time a player mines one of these ores, their level increases by 1.
3. Players can check their current level by using the command `/level`.
